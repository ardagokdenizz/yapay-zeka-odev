# 🧠 Yapay Zeka Temelleri Ödevi

## 📌 Proje Konusu
Çalışma süresine göre sınav başarı tahmini yapan makine öğrenmesi modeli.

## 📂 İçerik
- Veri seti oluşturma (Python + NumPy)
- Veri analizi (Pandas, Seaborn, Matplotlib)
- Makine öğrenmesi (Decision Tree)
- Model değerlendirme (Accuracy, Precision, Recall, F1)

## 🚀 Çalıştırma
1. Jupyter Notebook veya Google Colab aç
2. `yapay_zeka_odev.ipynb` dosyasını yükle
3. Tüm hücreleri çalıştır

## 📦 Gereksinimler
```
pip install pandas numpy matplotlib seaborn scikit-learn
```

## 🎯 Amaç
Makine öğrenmesinin temel adımlarını öğrenmek ve basit bir sınıflandırma modeli geliştirmek.
